# Onshape for FTC

In this course you learn to model robot parts in Onshape, a free CAD that runs in the browser. By the end, each module team (Shooter, Turret, Intake + Transfer, Chassis) builds its module as an assembly of goBILDA parts, and we order parts from that model.

## Meetings

| # | Meeting | Topic |
|---|---|---|
| 1 | [Lesson 1](lesson-1.md) | Sketches: draw, dimension, extrude |
| 2 | [Lesson 2](lesson-2.md) | Deeper into sketches: constraints, trim, mirror, patterns, offset |
