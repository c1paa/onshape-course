# onshape-course — context for Claude Code

Vlad (student, TLF scholar at The Island School, Limassol) runs a robotics/FTC club and teaches Onshape to ~15 students.
Site: https://c1paa.github.io/onshape-course/ (repo c1paa/onshape-course, GitHub Pages, MkDocs Material).

## How to work with Vlad
- Talk to Vlad in **Russian**, short and to the point. Site content is in **English**.
- Code: no comments, no extra blank lines, short variable names.
- Don't stall: no `sleep` loops; run long jobs in the background and keep working.
- Vlad reviews everything and sends corrections; apply them exactly, don't add extras he didn't ask for.
- Drawings: avoid clutter. No overlapping labels, no angle dims unless needed, holes on a circle = "n× Ød on ØPCD", no text paragraphs under drawings — dimensions instead.
- Commit/push only when asked (Vlad usually pushes himself). Never commit `private/` (passwords, users.sql).

## Repo layout
- `mkdocs.yml` — nav, `extra_javascript` (supabase-js CDN + `js/club.js?v=N`), `extra_css` (`css/club.css?v=N`). Bump `?v=N` after changing js/css. `not_in_nav: review.md`; `exclude_docs: advanced.md, submit.md, img/adv/`.
- `docs/index.md` — home, Meetings table (Lessons 1–4).
- `docs/lesson-1..4.md` — lessons. Lesson 4 = Assemblies (variables/configs overview, versions, mates, Derived, STEP, kit practice 4-1…4-5, kit images `docs/img/l4/`).
- `docs/homework-1.md`, `docs/practice.md` — generated by `tools/mkpage.py` (tasks T25–T39, required marks).
- `docs/review.md` — progress table (`#cl-review`, data-req / data-tasks).
- `docs/robot/` — Team robot: `index.md` + `sub-1..15.md`; images in `docs/img/robot/`.
- `docs/js/club.js`, `docs/css/club.css` — Supabase accounts, screenshot submissions (`.cl-sub[data-task]`), comments, review table (`overview()` RPC), Onshape link field (`.cl-link[data-task]` → table `links`).
- `supabase/*.sql` — setup.sql, overview.sql, links.sql (run by Vlad in Supabase SQL editor).
- `tools/draw.py` — SVG drawing helper (class S). `tools/tasks.py`, `tools/lesson2.py`, `tools/lesson3.py` — task/lesson drawings (CadQuery).
- `tools/robot/` — team robot generator:
  - `model.py` — all parts (CadQuery), `@part(code,name,sub,qty)`, placements, `SUB` (subassembly → student), `build()`.
  - `ann.py` — extra dims/notes per part (`d`, `n`, `o`, `c`, `a`, `sec`, `noord`, `nobox`).
  - `drawings.py` (+ `dwg.py` helpers: HLR views, collision-aware callouts) — part drawings.
  - `asm.py` — assembly sheets (assembled iso, side view, exploded with balloons).
  - `render.py` — shaded renders; `section.py` — turret section image.
  - `site.py` — regenerates `docs/robot/*` and `docs/img/robot/*` (full run ~9 min; `IDX=1` = index only).
  - `check.py` (pairwise interference), `holes_chk.py` (every screw hole has a partner), `ball.py` (ball path).
  - Needs: python3, cadquery/OCP, numpy, matplotlib, cairosvg, pypdf.
- `_to_delete/` (gitignored) — old files moved here instead of deleting.
